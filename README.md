## 🌟 חזון הפלטפורמה

**CourseForge** נוצרה במטרה לגשר על הפער בין סיכומי קורס סטטיים לבין הצרכים האמיתיים של סטודנטים לקראת בחינות אקדמיות.  
המערכת פועלת בשלושה רבדים מרכזיים:

1. **סביבת למידה ותרגול עמוקה (Course Study Engine)**: כל קורס מקבל פורטל אינטראקטיבי הכולל מעל 20 מסכים ייעודיים — החל מתיאוריה ונוסחאות KaTeX חדות, דרך מעבדות ויזואליות והרצת קוד חי, ועד לסימולציות מבחן מלאות, ניתוח דפוסי שאלות ומאגר טעויות אישי.
2. **מחולל Study Pack אוטומטי (NotebookLM-Style Pipeline)**: עיבוד מלא של הקלטות אודיו (m4a, mp3, wav) ותמלילי הרצאות — הפקת סיכומי עומק אקדמיים (מתרגל בכיר), איתור אוטומטי של דגשי מרצה ורמזים לבחינה (*"זה יהיה במבחן"*), ומיזוג לספר קורס שלם ללא כפילויות.
3. **סטודיו מאסטר מרובה קורסים (Multi-Course Master Studio)**: ניהול ויצירת קורסים מתוך קובצי סילבוס, מצגות ושאלונים (PDF, Word, TXT, JSON) ללא צורך בכתיבת קוד.

## 🚀 תכונות עיקריות

### 🤖 מחולל Study Pack אוטומטי (NotebookLM Pipeline)
- **העלאת קובצי אודיו והקלטות**: תמיכה בקובצי `.m4a`, `.mp3`, `.wav`, `.aac`, `.mp4` ותמלילים (`.txt`, `.pdf`, `.docx`, `.srt`, `.vtt`).
- **עיבוד מקבילי ברמת הרצאה בודדת**:
  - **סיכום אקדמי מעמיק (פרסונת מתרגל בכיר)**: תקציר TL;DR, הגדרות עם אינטואיציה + הגדרה פורמלית ב-LaTeX, משפטים והוכחות (Proof Idea), אלגוריתמים צעד-אחר-צעד, דוגמאות מודרכות ומלכודות נפוצות.
  - **דוח דגשי מרצה ורמזים למבחן**: סיווג היררכי אוטומטי: 🔴 **High Priority** (אמירות מפורשות כגון *"זה יהיה במבחן"*, *"חובה לדעת"*), 🟡 **Medium Priority** (דגשים חוזרים), ו-⚪ **מחוץ לתחום** (*"לא למבחן / רק להעשרה"*).
- **מיזוג לספר הקורס המלא (Master Course Book)**: איחוד כל ההרצאות למסמך קריאה רציף עם תוכן עניינים אינטראקטיבי מקושר (TOC) ונספח מרכז של כל דגשי המרצה.
- **ייצוא בלחיצה אחת**: הורדה כ-Markdown (`.md`), הדפסה / PDF, או המרה מיידית לקורס פעיל ב-CourseForge.

### 📅 יומן מבחנים וספירה לאחור חיה
- מונה דיגיטלי של ימים, שעות, דקות ושניות למועד א' ומועד ב'.
- תאריך בחינה גמיש הנשמר בפרופיל הסטודנט.
- אבני דרך אקדמיות (שבועיים לפני, שבוע לפני, 3 ימים לפני ויום לפני הבחינה).
- צ'ק-ליסט משימות יומי לשימור רצף הלמידה (Study Streak).

### 🗂️ כרטיסיות זיכרון חכמות בשיטת לייטנר (Leitner 5-Level Spaced Repetition)
- 5 רמות שליטה מדורגות להטמעה בזיכרון לטווח ארוך.
- היפוך תלת-ממדי חלק ואפקטי שמע סינתטיים עדינים (Web Audio API).
- שליטה מלאה במקלדת: <kbd>Space</kbd> להיפוך, <kbd>1</kbd> לדורש חזרה, <kbd>2</kbd> לידעתי היטב, <kbd>→</kbd>/<kbd>←</kbd> למעבר בין כרטיסיות.

### 👤 ניהול משתמשים ומחשבון יעד ומגן (GPA & Exam Simulator)
- ניהול פרופילי סטודנט נפרדים עם אווטאר אישי, מוסד אקדמי ותואר.
- הפרדת נתונים מקומית מוחלטת לכל סטודנט (התקדמות, שאלות וסימניות מבודדות).
- מחשבון ציון יעד: חישוב הציון המדויק הנדרש במבחן לפי משקל המגן והמטלות, עם התרעה על תנאי סף אקדמיים (כלל 55+) וסימון זכאות להצטיינות.

### 🧪 מעבדת המחשות אינטראקטיבית (13 Algorithm Visualizers)
המחשות צעד-אחר-צעד עם מעקב מצביעים ואינווריאנטים:
- **רשימות מקושרות**: הכנסה, מחיקה והיפוך רשימה במקום עם 3 מצביעים.
- **עצים בינאריים**: סריקות Inorder / Preorder / Postorder, הכנסה ומחיקה מ-BST.
- **עצי AVL**: גלגולים ימינה ושמאלה (LL, RR, LR, RL) ואיזון מחדש.
- **ערימות (Heaps)**: פעולות Heapify, Extract-Max, ובניית ערימה ליניארית ב-$O(n)$.
- **מיונים**: חלוקת Hoare Partition ב-Quicksort, ומיון מנייה (Counting Sort) יציב.
- **טבלאות גיבוב**: שרשור נפרד ומיעון פתוח.
- **עצים מועשרים (OS-Trees)**: שאילתות OS-Select ו-OS-Rank.

### 📐 רינדור מתמטי עשיר (KaTeX Math Typesetting)
- תמיכה מלאה ברינדור LaTeX (נוסחאות בתוך `$...$` או `$$...$$`) בכל חלקי האפליקציה: שאלות, פתרונות, פרקי לימוד, דפי נוסחאות וכרטיסיות.
- גופני KaTeX ארוזים ומותקנים מקומית לפעולה שוטפת ללא תלות ברשת.

### 🎨 עיצוב מודרני מינימליסטי, Dark & White Mode
- מעבר מהיר בלחיצה אחת בין מצב כהה (Dark Mode) למצב בהיר (White Mode) מסרגל ה-Topbar.
- עיצוב נקי בסגנון Linear / Apple עם ריווח אופטימלי (Whitespace) למניעת עומס קוגניטיבי.
- חיפוש מהיר בכל חלקי המערכת (Command Palette) באמצעות <kbd>⌘K</kbd> / <kbd>Ctrl+K</kbd>.

## ⚡ התקנה והפעלה מקומית

### דרישות קדם:
- **Node.js** (גרסה 18 ומעלה מומלצת)
- **Python 3** (אופציונלי, להרצת שרת ההפצה המקומי)

### 1. שכפול המאגר והתקנת תלויות:
```bash
git clone https://github.com/Yuval123malki/Course_Master.git
cd Course_Master
npm install
```

### 2. הרצת שרת פיתוח (Vite Dev Server):
```bash
npm run dev
```
האתר ייפתח בכתובת: `http://localhost:3000` עם Hot Module Replacement (HMR).

### 3. בניית גרסת Production ובדיקת קומפילציה:
```bash
npm run build
```

### 4. הרצת שרת ההפצה של פייתון (Production Server):
```bash
python3 serve.py 8080
```
האתר זמין בכתובת: `http://localhost:8080` עם שרת REST מקומי המספק שמירה קבועה לדיסק (`data/courses_db.json`).
